# 02 — Functionality Inventory

The complete, current inventory of Copernicus, as the evidence base for the kernel/plugin/backend
split (`00-kernel.md`). Each item is tagged by **layer**:

- **kernel** — a central, always-present component (viewport, terminal, UI, AI, wallet/RaaS).
- **plugin** — an opt-in UI surface (robots library, marketplace, coordination, VCS, RaaS).
- **backend** — a swappable robotics capability behind `tool <x>` (physics, IK, sensors, nav, RL,
  industrial, ROS2, Omniverse).
- **experimental** — present but incomplete ("coming soon", no backends, GPU-only).
- **dead** — never referenced, orphaned, or dormant.

This document is regenerated by audit; when code changes, this must be updated.

## Popup / separate-window patterns to eliminate

- **Publish panel** opens as a root-level full-window overlay — outside the shell chrome; fold into a screen.
- **Selectors** open as dimmed modals (use the single `ModalLayer`, not three parallel mechanisms).
- **`change_scene_to_file`**: already zero live call sites; formalize as forbidden.
