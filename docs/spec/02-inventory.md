# 02 — Functionality Inventory

The complete, current inventory of Copernicus, as the evidence base for the component tree and signal
backbone. Each item is marked **wired** (reachable from the shell), **orphaned** (exists but not
reachable), or **dead** (never referenced). This document is regenerated by audit; when code changes,
this must be updated.

## Popup / separate-window patterns to eliminate

- **Publish panel** opens as a root-level full-window overlay (`PublishPanel.show_for_robot`) — outside the shell chrome.
- **Selectors** open as dimmed modals (acceptable, but must use the single `UiModal`, not three parallel mechanisms).
- **ROS Coder** is a child of the AI tab (acceptable), but is a self-contained mini-IDE rather than a composed view.
- **`change_scene_to_file`**: already zero live call sites; formalize as forbidden.
